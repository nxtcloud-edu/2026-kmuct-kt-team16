Snaptok — AI Memory Agent (단일 파일 웹 데모)

실행 방법
- index.html을 더블클릭해서 브라우저로 열면 바로 실행됩니다. 별도 설치/빌드 없음(순수 HTML+CSS+JS, 프레임워크 없음).
- 이미지를 실제로 읽는 AI 분석 기능은 Claude 아티팩트 런타임(claude.use('sample'))에 의존합니다.
  로컬 파일로 그냥 열거나 다른 서버에 올리면 이 부분은 자동으로 "파일명 기반 데모 분류"로 대체됩니다.
  실제 AI 분석까지 보려면 Claude.ai에서 이 파일을 아티팩트로 게시한 링크로 접속해야 합니다.

구성
- index.html 안에 HTML/CSS/JS가 모두 포함되어 있습니다(단일 파일).
- 로고 이미지는 base64로 파일 안에 인라인되어 있습니다.
- 데이터(보관함/캘린더/위치알림 등)는 브라우저 localStorage에 저장됩니다. 기기·브라우저별로 별도 저장됩니다.

주요 기능
- 스크린샷/사진 다중 업로드 → AI 이미지 분석(행동/기억/불확실 분류) → 캘린더 자동 등록 또는 보관함 자동 저장
- 지오펜스 위치 알림(시뮬레이터 모드 기본, 실제 GPS 모드 지원)
- Snaptok Wrapped(결산) — 실제 저장 데이터 기반 요약, AI 관심사 요약(온디맨드 Claude 호출)
- 되돌리기(Undo), 중복 감지, 확인 필요 큐 등
